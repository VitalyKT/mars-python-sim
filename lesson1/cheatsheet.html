📋 ПРОТОКОЛ НАВИГАЦИИ №1

🚀 1. ИНИЦИАЛИЗАЦИЯ (СТАРТ) 
import turtle          # Загружаем модуль
rover = turtle.Turtle() # Создаем ровер
🕹️ 2. КОМАНДЫ ДВИЖЕНИЯ
Команда Действие
rover.forward(100) Вперед на 100 пикселей
rover.backward(50) Назад на 50 пикселей
rover.left(90) Поворот влево на 90°
rover.right(45) Поворот вправо на 45°
📝 3. ТЕРМИНОЛОГИЯ

• Библиотека (turtle) — склад инструментов.

• Объект (rover) — твой личный робот.

• Метод (forward) — команда, действие.

• Аргумент (100) — уточнение (на сколько ехать).
