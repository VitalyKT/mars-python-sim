🚀 ШПАРГАЛКА НАВИГАТОРА: ОСНОВЫ TURTLE 📡

🛠️ 1. Что такое Библиотеки (Модули)
В базовом наборе Python умеет не так много. Всё остальное хранится на «складе».
Библиотека (Library) — это набор готового кода, который написали другие программисты, чтобы мы не изобретали марсоход с нуля.
import turtle # Вызываем модуль "turtle" со склада в программу
🤖 2. Создание Объекта
Нужно выкатить ровер на поверхность.
Объект (Object) — это конкретный экземпляр чего-либо. Библиотека — это чертеж, а rover — твой личный аппарат.
rover = turtle.Turtle() # Создаем объект-ровер
🎮 3. Методы и Аргументы
Метод (Method) — действие, которое умеет выполнять объект (пишется через точку).
Аргумент (Argument) — уточнение для команды внутри скобок (насколько далеко? какой угол?).
имя_объекта.метод(аргумент)
🗺️ 4. Основные команды навигатора
⬆️ rover.forward(100)
Ехать вперед на 100 пикселей (космических метров).
⬇️ rover.backward(50)
Ехать назад на 50 пикселей.
↩️ rover.left(90)
Повернуть влево на 90 градусов.
↪️ rover.right(45)
Повернуть вправо на 45 градусов.
📝 Подведем итог
Протокол для старта движения (вперед на 100):
import turtle # 1. Загружаем модуль
rover = turtle.Turtle() # 2. Создаем объект-ровер
rover.forward(100) # 3. Вызываем метод движения
